# Ninours

Jeu web mobile : Ninours, un ourson en apnée, accompagné de son copain koala sur un bateau.

- `index.html` — le jeu complet (un seul fichier, à jouer à l'horizontale)
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png`, `favicon.png` — icône et réglages pour l'installer sur l'écran d'accueil
- `ninours-classement.gs` — script Google Apps Script du classement (Google Sheets)
- `netlify.toml` — Netlify publie la racine du dépôt, sans build

Chaque push sur `main` est mis en ligne automatiquement par Netlify une fois le dépôt relié au site.
